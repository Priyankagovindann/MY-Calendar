MY-CALENDAR
A unified, calendar-first web utility built to eliminate context-switching between daily task planners and personal expense trackers. Instead of managing schedules and budgets in separate apps, users view tasks, deadlines, and daily spending (in ₹) on a single date-centric interface.
 
 Features
- User registration and login
- Calendar view with events and a to-do list
- Income and expense tracking
- Reports and summaries
- Personal vault
- User profile management
- Admin panel (dashboard, user management, activity log)

Tech Stack
- PHP
- MySQL (update if different)
- HTML, CSS, JavaScript
